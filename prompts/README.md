# Промпты проекта AI-инфлюенсера

`MASTER_PROMPT_AI_INFLUENCER.md` содержит основной мастер-промпт и используется как основной регламент проекта AI-инфлюенсера.

Мастер-промпт нужно выполнять поэтапно, а не целиком. Каждый этап должен завершаться сохранением результата в отдельный файл и остановкой перед переходом к следующему этапу.
